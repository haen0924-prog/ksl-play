사용설명서

① 화면 소개 (위쪽 메뉴)

학습카드

그림이나 영상을 보고 단어를 떠올립니다. "정답 보기"로 단어를 확인하고, "5초 생각하기"로 먼저 생각할 시간을 줄 수 있어요.

짝맞추기

처음 미리보기 시간 동안 카드 위치를 외운 뒤, 같은 그림과 단어의 짝을 찾습니다. 화면 위의 2쌍 · 4쌍 · 8쌍 버튼으로 카드 수를 고를 수 있어요. 미리보기는 2쌍 2초, 4쌍 3초, 8쌍 5초입니다.

단어 퀴즈

그림을 보고 4개 중 맞는 단어를 고릅니다. 끝나면 이름을 적고 점수를 저장할 수 있어요.

점수 기록

학생별 평균과 최근 기록을 봅니다. 엑셀(CSV) 파일로 받을 수도 있어요.

✏
문제 만들기

단어, 그림, 영상을 넣고 고치는 곳입니다.

② 수업 범위 고르기 ( 단원)

단원 선택

학습카드, 짝맞추기, 퀴즈 화면 위쪽의 수업 범위에서 단원을 고르면 그 단원의 문제만 나와요. 기본은 "전체"입니다.

④ 영상 넣기

영상 링크

유튜브 주소를 "영상 링크" 칸에 붙여넣습니다.

영상 파일

" 영상 파일 올리기"로 컴퓨터의 영상을 고릅니다. 60MB 이하만 가능해요.

⑤ 저장과 백업

자동 저장

문제와 점수는 이 컴퓨터의 브라우저에 자동으로 저장됩니다.

백업

" 백업 저장"으로 파일을 받아 두면 다른 컴퓨터에서 " 백업 불러오기"로 가져올 수 있어요.

백업 파일에는 글과 사진, 영상 링크가 들어갑니다. 영상 파일은 빠지니 다시 올려 주세요. 점수 기록은 엑셀(CSV)로 따로 받아 두는 것이 안전합니다.

⑥ 큰 화면으로 보기

큰 화면 버튼

학습카드, 짝맞추기, 단어 퀴즈 화면마다 있습니다. 누르면 화면이 전체 화면으로 커집니다.

✕
끄기

"✕ 큰 화면 끄기" 버튼이나 Esc 키를 누르면 원래 화면으로 돌아갑니다.

← → / 스페이스

학습카드에서 화살표로 넘기고, 스페이스로 정답을 보이거나 가립니다.

⑦ 학습카드 사용 순서

1. 그림·영상 보기

그림이나 영상을 보고 단어를 떠올려 봅니다.

2. 5초 생각하기

버튼을 누르면 그림 위에 숫자 5, 4, 3, 2, 1이 나옵니다. 그림과 영상은 그대로 보입니다.

3. 정답 나오기

숫자가 0이 되면 단어가 자동으로 나옵니다.

4. 가리기

"다시 가리기" 버튼이나 스페이스 키로 정답을 다시 숨길 수 있어요.

▶
5. 다음 문제

"다음 ▶"을 누르면 다음 그림으로 넘어갑니다. ← → 키로도 넘길 수 있어요.

"정답 보기"를 누르면 바로 단어가 나오고, 다시 누르면 가려집니다.

⑧ 점수 기록 사용법

1. 단어 퀴즈 풀기

그림을 보고 보기 4개 중 알맞은 단어를 고릅니다. 맞히면 점수가 1점 올라가요.

✍
2. 이름 적기

퀴즈가 끝나면 학생 이름을 적어 주세요. 비워 두면 "이름 없음"으로 저장됩니다.

3. 점수 저장

" 점수 저장"을 누르면 기록에 남습니다. 저장 후에는 " 저장됨"으로 바뀝니다.

4. 기록 보기

단어 퀴즈 화면 아래의 " 최근 점수 보기"에서 최근 5건을 바로 볼 수 있어요. 전체는 메뉴의 " 점수 기록"에서 봅니다.

5. 엑셀로 받기

점수 기록 화면의 " 엑셀(CSV) 받기"를 누르면 파일로 저장되어 엑셀에서 열 수 있어요.

점수는 단어 퀴즈 · O,X 퀴즈 · 선 긋기 퀴즈에서 저장됩니다. 학습카드와 짝맞추기는 점수가 남지 않아요.
점수 기록 화면 위의 단원 칸에서 "전체" 또는 단원 이름을 골라 보면, 그 단원의 기록만 따로 볼 수 있어요.
전체 엑셀 받기는 모든 기록을, 단원별 엑셀 받기는 단원 칸에서 고른 단원의 기록만 파일로 받습니다. 파일 이름에 단원 이름이 들어가요.
점수는 지금 쓰는 컴퓨터(브라우저)에만 저장됩니다. 다른 컴퓨터에서는 보이지 않으니 중요한 기록은 엑셀로 받아 두세요. 기록은 줄별로 삭제할 수 있고, "전체 지우기"는 되돌릴 수 없어요.
점수 기록 예시 화면 보기 (4명이 여러 번 푼 경우)

한 번 저장할 때마다 최근 기록에 한 줄씩 쌓입니다. 학생별 평균은 같은 이름끼리 묶여서 계산돼요.

⑨ O,X 퀴즈 · 선 긋기 퀴즈

O,X 퀴즈

그림을 보고 화면에 나온 단어가 맞으면 , 틀리면 를 누릅니다. 한 번에 최대 10문제가 나와요.

선 긋기 퀴즈

왼쪽 그림을 누른 뒤 오른쪽 단어를 누르면 선이 이어집니다. 잘못 이었으면 이은 칸을 다시 누르면 지워져요.

채점하기

선 긋기는 다 이은 뒤 " 채점하기"를 누르세요. 맞은 선은 초록색, 틀린 선은 빨간색으로 보입니다.

점수 저장

끝난 뒤 " 점수 저장"을 누르면 기록에 남습니다. 점수 기록 표에서 "종류" 칸으로 어떤 퀴즈인지 구분할 수 있어요.

사진이나 영상이 있는 문제만 게임에 나옵니다. 선 긋기 퀴즈의 영상은 칸 안에서 바로 재생하고, 아래 '이 칸 선택'을 눌러 선을 잇습니다.
